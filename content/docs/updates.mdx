## macOS Limitation

Do not treat current unsigned macOS builds as fully automatic update builds. Manual download and replacement remains the reliable route until Axon ships with an Apple Developer certificate, hardened runtime, and notarization.

## Source Of Truth

GitHub Releases are the source of truth for changelog entries, release notes, and platform downloads.
