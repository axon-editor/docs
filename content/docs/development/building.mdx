Axon is open source. You can build the editor from source to test the latest changes, contribute patches, or create custom builds.

## Prerequisites

- Node.js 22.x.
- npm 10 or later.
- Go v1.25.1 or later.
- Git for cloning the repository.
- `make` is optional for build scripts.

## Clone

```bash
git clone https://github.com/axon-editor/axon
cd axon
```

## Development Mode

The root development command builds shared packages, starts `axon-core`, starts the dedicated `axon-pty-host`, starts Vite, and launches Electron together:

```bash
npm install
npm run dev
```

Development uses authenticated Core and PTY services on `127.0.0.1:17777` and `127.0.0.1:17778`. Packaged launches choose private ports unless `AXON_CORE_PORT` or `AXON_PTY_PORT` is explicitly set.

## Production Build

```bash
npm run build
npm --workspace axon run pack
```

Platform packages:

```bash
npm --workspace axon run dist:mac
npm --workspace axon run dist:win
npm --workspace axon run dist:linux
```

Build output goes to `apps/editor/release/`.

## Language Servers

```bash
npm --workspace axon run build:language-servers
```

Normal release packaging keeps Go and npm-backed servers with Axon while native and runtime-heavy tools install through Language Tools. The download script is for development and language-tool preparation, not a requirement for every contributor running the editor.

## Project Structure

```txt
axon/
├── apps/editor/          # Electron, React, Monaco, preload, and main process
├── services/core/        # Go Core, dedicated PTY host, filesystem, and agent CLI
├── packages/             # shared extension, protocol, IPC, and config contracts
├── extensions/           # built-in and local marketplace extension packages
├── build/                # repository build orchestration
├── tools/                # maintenance and validation scripts
└── docs/                 # release and engineering notes
```
