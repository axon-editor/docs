Axon's editor is built for daily project work: open files, keep multiple panes active, preview Markdown and media, and protect dirty changes before a tab closes. The Axon Buffer Engine keeps document identity, cached disk text, dirty state, and shared Monaco models stable while Monaco remains the text renderer and editing engine.

## Tabs and Panes

Files open into editor tabs. Tabs can be moved between panes, pinned, and closed with dirty-file prompts when unsaved changes exist.

Restored tabs do not all mount Monaco, synchronize with language servers, and start watchers during first paint. Axon restores the visible editing surface first and activates deeper work as the relevant file becomes active.

Recently opened clean buffers remain available under bounded memory and entry budgets, so switching back to a file can attach its existing model without showing an empty one-line editor. Disk fingerprints and watcher invalidation prevent a cached buffer from hiding agent, formatter, or external file changes.

## Previews

Markdown, images, videos, and HTML can open in preview surfaces. External links use the system browser, while local Markdown links stay inside Axon when the target file exists in the workspace.

Markdown preview supports GitHub-flavored tables and task lists, Mermaid diagrams, KaTeX math, footnotes, callouts, frontmatter, heading links, a generated table of contents, theme-aware highlighted code fences, copy actions, PDF export, and synchronized editor/preview scrolling. Preview tabs render the current dirty editor buffer instead of waiting for the file to be saved.

## Code Snapshots

Run **Code Snapshot** from the command palette or use the camera action in the status bar while a real file is active. Axon opens the snapshot builder as an editor tab instead of interrupting the current workspace with a modal.

The builder can select a line range, rename the displayed file, change export width, padding, and font size, and toggle file metadata or line numbers. Palette choices include the active Axon theme plus Graphite, Paper, Forest, and Plum. Syntax colors come from the active theme capture table, so JSON object keys retain property styling instead of being flattened into ordinary strings.

Copy PNG writes the rendered image to the system clipboard. Save PNG opens the native save dialog. Both actions wait for fonts, syntax rendering, and the Axon logo watermark before export, so the saved image matches the visible preview.

## Indentation And Guides

Editor settings control tab width, spaces or tabs, automatic indentation detection, code left spacing, indentation guides, active indentation highlighting, and bracket-pair guides. Changes apply to the mounted Monaco editor and shared text model immediately; reopening the file is not required.

Changing tab width or spaces/tabs in Settings disables automatic detection so the selected fixed values take effect. Indentation guides can be hidden independently while bracket-pair guides retain the active scope indicator.

## Find In File

Use the editor find control for current-file search. Selected text seeds the query when opening find, and editing the find query does not steal the original editor cursor after a query already exists.

## File Commands

- Save As opens the native file picker and writes through the workspace capability boundary.
- Open Recent reuses the normal workspace-opening flow instead of maintaining a separate partial path.
- Workspace replace skips binary, generated, and oversized files, then writes matching text files atomically.
- Language grammars load as lazy chunks through a shared tokenizer engine.
- Semantic coloring, language-server synchronization, and React snapshots are coalesced away from the per-keystroke path.
- Completion documentation and auto-import edits resolve lazily for the focused item, while the completion popup stays narrow and dense.
- JSON object keys and quoted Python dictionary keys use property styling; quoted values remain strings.

## Large Documents

Files at or above 2 MB or 20,000 lines enter large-document mode. Axon keeps text editing and scrolling responsive while disabling expensive work such as semantic-token overlays, language-server synchronization, Git line paint, line trace, and unbounded find decoration creation.

Workspace text reads are cached in the main process with metadata fingerprints, shared in-flight reads, and bounded memory. A file modified while it is being opened is retried instead of publishing mixed or stale bytes. Text files larger than 32 MB are rejected by the normal editor path rather than decoding enough data to freeze the app.

## Problems

Diagnostics from connected language servers are collected into a workspace view where errors, warnings, information, and hints can be filtered before opening the affected file.

## Stability Rules

- Dirty saves preserve the current scroll position instead of jumping to the bottom of the file.
- Change decorations are replaced instead of stacked.
- Command/control-click is the explicit jump-to-definition gesture for imported and exported symbols.
- TypeScript hover rendering avoids competing stacked hover cards.
- Embedded HTML in TSX/JSX receives themed token colors instead of falling back to plain white text.
- HTML preview occupies the full editor height and sends browser console messages to Axon's Output tab instead of reserving a terminal below the preview.
- `Cmd/Ctrl+S` routes through the active editor model, preserves scroll position, records the new disk baseline, and refreshes Git paint without reopening the tab.
