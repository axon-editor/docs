## Opening Search

- Click the Search icon in the sidebar.
- Use `Cmd+Shift+F` on macOS or `Ctrl+Shift+F` on Windows/Linux.
- Use the command palette action `Search Workspace`.

## Search Features

- Case-sensitive search.
- Whole-word matching.
- Regular expression patterns.
- Project-aware exclusions from Git ignore rules, configured workspace exclusions, generated directories, vendor content, virtual environments, caches, and binary paths.
- Cancellation of obsolete searches when the query or workspace changes.
- Bounded asynchronous traversal so large directory trees do not block Electron's main thread.
- Replace in files across multiple results.

## Results

Results are grouped by file with line numbers and surrounding context. Click any result to jump directly to that line and column.

## Exclusions

Axon combines built-in generated/binary safeguards with the active project's ignore configuration. It does not depend only on a short hardcoded folder-name list, so project-specific virtual environments, generated outputs, and ignored trees can remain outside normal search work.
