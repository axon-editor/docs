Axon includes a PTY-backed integrated terminal owned by a dedicated Go PTY host and rendered through xterm.js. The main Core service does not own terminal byte transport, so Core recovery and workspace operations cannot interrupt an otherwise healthy shell session.

## Opening The Terminal

- Click the Terminal icon in the sidebar.
- Use `Cmd+J` on macOS or `Ctrl+J` on Windows/Linux.
- Run `Toggle Terminal` from the command palette.

## Terminal Tabs

- Create a new tab with the plus button or the `New Terminal` command.
- Close a tab with its close button.
- Rename a tab by double-clicking the tab title.

## Behavior

- Full PTY support for interactive programs.
- Copy and paste with `Ctrl+Shift+C` and `Ctrl+Shift+V`.
- WebSocket connection to the Go backend for real-time I/O.
- Persistent sessions across renderer reloads.
- Scrollback replay when a terminal view reconnects.
- 200,000 lines of visible xterm scrollback per terminal tab.
- Bounded byte and write queues for long-running agent output.
- Output acknowledgement only after xterm has committed the bytes, not merely when the renderer receives them.
- Slow or reconnecting renderers resume from the last committed byte instead of skipping queued output.
- Reading older scrollback does not enable live-tail following; newly committed output remains at its real buffer position until you scroll to it.
- Frame-coalesced viewport repainting keeps detached scrollback visibly current after background output pushes rows beyond the viewport.
- Small input bursts survive websocket reconnects.
- Terminal profiles and panel activation are declared by the built-in terminal extension.

Scrollback is intentionally bounded. Within the retained 200,000 lines, ordered output should remain visible unless the terminal is explicitly cleared, closed, or the oldest lines age out of that limit.

## Axon CLI

Use `axon` for an interactive Axon Agent session, `axon .` to open the current project in Axon, and `axon resume` to continue a saved workspace conversation.
