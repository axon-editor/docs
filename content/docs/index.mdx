## Important Notes

- macOS builds are unsigned personal builds until signing and notarization are available.
- Native and runtime-heavy language servers install on demand, while Go and npm-backed servers ship with Axon.
- Python projects automatically discover validated environments and expose both the environment folder and resolved interpreter in Settings.
- Update checks use GitHub Releases, but unsigned macOS builds may still require manual replacement.
